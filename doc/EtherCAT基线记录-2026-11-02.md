## 3. PDO 布局实际值

来源 `framework/drivers/communication/ethercat/core/spec/ecat_pdo_layout.hpp`。

| 项 | 定义 | 实际值 |
| --- | --- | --- |
| `PdoOutputs`（主站→从站，RxPDO） | `uint32_t counter[64]` | 64 字 / **256 B** |
| `PdoInputs`（从站→主站，TxPDO） | `uint32_t counter[64]` | 64 字 / **256 B** |
| `kProcessOutputWords` | `sizeof(PdoOutputs) / 4` | 64 |
| `kProcessInputWords` | `sizeof(PdoInputs) / 4` | 64 |
| `kMaxProcessOutputSize` | `kProcessOutputWords * 4` | 256 |
| `kMaxProcessInputSize` | `kProcessInputWords * 4` | 256 |

两方向对称，各 64 UDINT / 256 B。CA 映射表所需缓冲 = `2 + 4 × 64` = **258 B**，与原文 §7.1 一致。

> 注：模板化门面规划 `§P1.5` 提到"当前代码实际是 8 UDINT / 32 B"，与本次工作区源码不符，以本表为准。
