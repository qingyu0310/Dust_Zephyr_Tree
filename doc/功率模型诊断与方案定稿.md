## 3. 诊断：模型看出了什么（六个证据）

### 3.1 K1/K2 反相关复发 → 双参数不收敛（r = −0.84）

全局 pearson(K1, K2) = **−0.840**；300 行滑窗 37 窗中 35 窗 r < −0.5。

分段中值（每 500 行）：

| 行 | K1 | K2 |
|----|------|------|
| 0–499 | 0.405 | 0.400 |
| 1000–1499 | 0.794 | 0.304 |
| 2500–2999 | 0.717 | 0.303 |
| 4000–4499 | 0.959 | 0.208 |
| 5500–5786 | 1.196 | 0.182 |

**K1 从 0.40 单调爬到 1.20（漂 3 倍），K2 从 0.40 镜像降到 0.18** —— 与记忆里 v2 末期 5883 行的双参数反相关（K1 1.85~2.32 / K2 0.0057~0.0121）**完全同型**。

> 结论：v3 把 ω² 换成 |ω| **没有消除共线**。驾驶时 τ 和 ω 永远同涨同落 → Στ² 与 Σ|ω| 高度相关 → 2 参 LS 解不唯一 → 残差任意分摊到 K1/K2 → 镜像漂移。共线是**工况本质**，不是模型形式（ω² vs |ω|）问题。

### 3.2 稳态误差 7W 超 3W 目标，离线最优也只有 4.6W

工况分型误差（P_pred 用实时 K1/K2 重算）：

| 工况 | n | P_meas中值 | \|err\|均 |
|------|----|-----------|----------|
| 稳态巡航 | 4344 | 36.7W | **7.2W** |
| 加速段 | 820 | 70.9W | 23.0W |
| 减速段 | 370 | 21.0W | 41.3W |
| 极端瞬态 | 117 | 153.7W | **105.9W** |

分离诊断（离线 lstsq 在稳态段拟合，绕开 RLS 收敛问题）：

| 方案 | 稳态 \|err\|均 |
|------|--------------|
| **离线最优** K1=2.23, K2=0.13 | 4.63W |
| 在线 RLS 末值 K1=1.20, K2=0.18 | 4.68W |
| 初值 K1=2.20, K2=0.10 | 6.30W |

> **关键**：在线 RLS 误差（4.68W）≈ 离线最优（4.63W）。RLS 已经跑到了模型结构能做到的最好。剩下的 4.6W 是**模型结构下限**，调 λ / 调闸门 / 换初值都救不了。

### 3.3 截距 +3.5W：模型缺一项系统损耗（Kτ·ω ≠ 1）

离线拟合 `P_meas = K1·Στ² + K2·Σ|ω| + Στ·ω + C`（固定 Kt=1.0），得 **C = +3.49W，显著非零**（理论应为 0）。

放开 Kt 的三参数拟合：`K1=2.04, K2=0.09, Kt=1.13, C=6.83W`，残差 stdev 7.0W / \|err\|均 3.8W。

> 物理解释：**Kt≈1.13 ≈ 1/0.88**。功率计读的是**输入电功率**，而模型把 τ·ω 当作 100% 机械输出。减速箱 + 电机内部机械损耗（效率 η≈0.88）的那部分没人认领 → 全部积成截距/残差。这正是"截距 3.5W"的来源。
>
> 注：三参数里 Kt 与截距 C 强共线（Στ·ω 恒正），Kt=1.13 与 C=6.83 互相抵消，单看不可靠，但**方向明确**：τ·ω 项需要放大系数，或模型需要额外的随 τ·ω 增长的损耗项。

### 3.4 误差按 Σ|ω| 分箱非单调 → 中间转速段系统性低估

用离线最优系数回代，残差按 Σ\|ω\| 分箱：

| Σ\|ω\| | n | err mean | stdev |
|--------|----|----------|-------|
| 0–20 | 491 | −1.4W | 7.2 |
| 20–40 | 349 | **+7.5W** | 11.3 |
| 40–60 | 300 | **+13.2W** | 14.7 |
| 60–80 | 1613 | +3.3W | 3.6 |
| 80–100 | 1591 | +2.4W | 3.2 |

> 40–60 rad/s 段低估 13W、高速段反而回落——**非线性偏置**，说明摩擦/损耗不是简单线性于 \|ω\|，也不是单一 K3 能吸收的。

### 3.5 瞬态 100W 级误差：惯性功率未建模（物理无解）

- 极端瞬态 \|err\|均 105.9W，P_meas 峰值 444.7W（`行329: Στ²=21.6, Σ|ω|=94.4, Στ·ω=306.6`）
- 减速段 err mean **+41W**：功率计读正（再生被吸收），模型因 Στ·ω<0 预测为负

> 加减速时 P_meas 含**动能变化率**（惯性功率），瞬时模型 `k1·τ²+k2·|ω|+τ·ω+K3` 物理上解释不了。这部分只能靠裁判 60J 能量缓冲 / 预算剔除兜底，不是模型能修的。

### 3.6 K3=3.1 验证通过（排除 K3 嫌疑）

- 静止段（Σ\|ω\|<0.5, Στ²<0.01）91 行：P_meas 均值 **3.066W**，偏差 **−0.034W**
- 低功耗段（0<P_meas<6W）500 行：P_meas 2.54 vs P_pred 2.77
- 死区 5W > K3 3.1W → 静止永不触发 RLS，K3 不被辨识污染

> **K3 判定方法（可复用）**：全停车时功率计读数应恰好等于 K3。数据证明 K3=3.1 正确，**不用动**。

## 4. 根因判定（为什么之前方案都没解决）

### 4.1 共线是工况本质（最根本）

| 层级 | 结论 |
|------|------|
| 表面 | K1/K2 反相关、镜像漂移 |
| 直接原因 | 双参数 RLS 在驾驶激励（τ、ω 同涨同落）下无唯一解 |
| 深层 | **v3 换 \|ω\| 没解决共线**——因为根因不是 ω² vs \|ω\| 的模型形式，而是"Στ² 与转速项永远同涨同落"的**工况结构** |
| 佐证 | 记忆：v2 末期 5883 行双参数反相关 → v3 验证（本文 5787 行）**同样反相关**，两次都是双参数 |

### 4.2 模型缺项 → 有结构残差

截距 +3.5W / Kt≈1.13 → 减速箱效率 η≈0.88 的机械损耗未建模。双参数只能把残差在 K1/K2 间分摊，摊不干净（3.4 分箱的非线性就是残余）。

### 4.3 λ=0.99999 慢遗忘 → "单调漂移"假象

K1 单步跳变**只有开头 3 处**（都是开机首次大加速），之后全是微小步进缓慢移动 → "慢遗忘 × 有结构残差 = 单调随机游走"。看着像稳定，实际在漂。

### 4.4 瞬态惯性功率 → 瞬时模型物理无解

加速/重刹时 P_meas 尖峰到 444W，模型解释不了，只能靠能量缓冲兜底。

## 6. 决策：用什么模型、要不要静态标定

### 6.1 模型形式（定稿）

```
P = K1·Στ² + K2·Σ|ω| + Kt·Στ·ω + K3
```

- **保留 \|ω\| 线性项**：天津/港科大共识，摩擦接近线性于 ω，比 ω² 拟合好。✅ 保留
- **补 Kt（τ·ω 系数）**：数据证明 Kτ·ω≠1（≈1.13，减速箱效率），这是截距 3.5W 的来源。✅ 新增
- **K3 = 3.1**：静止实测验证。✅ 不动

### 6.2 辨识策略：**用静态标定，但不是退化成纯冻结**

回答"要用静态标定方案吗？"——**要，但走混合方案 D**：

1. **Kt、K2 必须静态标定**：截距 3.5W 只能靠加 Kt 项消，而加 Kt 后是 3 参数，在线 RLS 在共线激励下更不可能收敛 → Kt/K2 只能离线 lstsq 标定，然后**冻结**（它们不随温升剧烈变化）。
2. **K1 留在线单参数微调**：K1 是铜损系数，随绕组温度/电压变化最敏感 → fix-K2 单参数 RLS 只辨 k1（记忆验证 v2 单参数收敛 2.33W）。
3. 这样既解决模型缺项（离线），又保留自适应（在线），又规避共线（单参数）。

> 标定工况：**架起空转标 K2 + 怼墙标 K1**（§7.2），全程走现有 PID 管线，下地车均可做，绕开"小陀螺飘做不了稳定测试"的约束。

> 纯静态标定（方案 C）作为**备选**：如果混合方案在比赛前不稳定，退回 C 全冻结（COD 的做法），损失温升自适应但获得确定性。

## 7. 静态标定方案（详细可执行）

### 7.1 标定参数与模型

固定 K3=3.1（静止实测），离线拟合：

```
P_meas = K1·Στ² + K2·Σ|ω| + Kt·Στ·ω + 3.1
```

3 个未知数，回归量 [Στ², Σ|ω|, Στ·ω]。**固定 K3 再拟合**，避免 Kt 与截距共线抵消（本文 3.3 三参数拟合 C=6.83 即此病，需在标定时避开）。

### 7.2 工况设计（解耦 Στ² / Σ|ω| / Στ·ω）

目标：让三个回归量**独立变化**，否则 lstsq 病态。**全程走现有 PID 控制管线**（ReadRemote → PID → PowerAlloc → 8 列日志），不写标定专用逻辑，遥控推杆即可：

| 工况 | 怎么跑 | 期望覆盖 | 作用 |
|------|--------|---------|------|
| 静止（所有轮停） | 不推杆 | Στ²≈0, Σ\|ω\|≈0, Στ·ω≈0 | 定 K3（已验证 3.066） |
| **架起高速空转** | 底盘架起、轮离地，遥控推不同速度档（低/中/高各稳几秒） | Σ\|ω\| 大, Στ² 小 | **定 K2**（P_meas−K3 ≈ K2·Σ\|ω\|） |
| **怼墙堵转** | 顶墙 PID 推满大电流，限流短跑分段 | Στ² 大, Σ\|ω\|≈0 | **定 K1**（P_meas−K3 = K1·τ²） |
| 急加减速（τ·ω 变化大） | 下地/架起急推急刹 | Στ·ω 大范围 | 定 Kt（或减速箱效率先验 ~1.1） |

**为什么必须专门工况（实测警示）**：用现有下地 vofa+.csv 拟合 K2 **不稳**——高速段分箱拟合 K2 在 **−0.086 ~ +0.103** 间乱跳甚至为负。原因是现有"高速段"实际带载跑（Στ² 不小），τ² 与 \|ω\| 仍共线 + Kt 偏置污染。**K2 只能靠架起空转（τ→0）取干净值**。

- 架起空转时 Στ² 只剩摩擦分量（估 ~0.1-0.3 vs 下地 0.52），K1·Στ² ≈ 0.3W 相对 K2·Σ\|ω\| ≈ 9W <5%，一维拟合成立
- 怼墙时 PID 积分饱和输出最大电流 → τ 恒定点；要多个 τ 档可临时调电流限幅或用不同目标速度
- 安全：怼墙堵转发热快，**限流短跑**（几秒分段）；架起注意轮子悬空别擦地、线缆别卷进轮子
- 本方案解决记忆约束："偏心车小陀螺会飘，做不了稳定测试"——架起/怼墙均为下地车可控工况

### 7.2.1 标定前 PID 质量验证（30s 确认，不用专门调参）

标定全程用现有下地调好的 PID（trd_chassis.cpp `speed_cfg.kp=10, ki=1, kd=0`）。标定输入是实测 τ/ω/P_meas，PID 只是产生电流的中间层——**PID 调得差只是让数据更噪，不是不能用**。但录数据前必须验证：

**架起空转录 30s 看日志**：
- ✅ Σ\|ω\| 平稳、Στ² 中值 < 0.3 → 稳速 OK，K2 能干净拟合，直接标
- ⚠️ Σ\|ω\| 来回摆、Στ² > 0.5 → PID 空转**震荡**（超调，τ 正负乱跳）→ **先降 kp（或加 kd）再标**，否则 K2 被污染

**怼墙看日志**：
- ⚠️ Στ² 太小（<1）→ 电流没顶上去，K1 信噪比低 → 加大 PID 输出限幅，或等积分饱和更久

一轮 30s 就够确认，不达标才微调 PID。

### 7.3 数据采集要求

- **复用现有 8 列日志（P_meas, Στ², Σ|ω|, Στ·ω 已全含）+ 现有 PID 控制管线，无需改代码/控制逻辑**
- 日志周期 50ms（trd_chassis.cpp `Timer log_timer(50)`），总录制约 **1.5-3 分钟，1000-2000 行**

| | 怼墙堵转 | 5-10s 分段 | 100-200 | K1 单点 |

## 10. 风险与约束

| 风险 | 说明 | 对策 |
|------|------|------|
| 标定工况解耦不足 | 下地车跑不出"低速大力矩"（小陀螺飘） | 多趟正常跑 + 3σ 剔除；Kt 用物理先验（减速箱 η）兜底 |
| 温升/电压漂移 | 冻结 K2/Kt 后长期运行仍会偏 | K1 在线单参数微调承担自适应 |
| 稳态误差仍有 ~3.5-4W 下限 | 即使三参数标定完美，stdev 7W（功率计噪声/微动态） | 3W 硬指标可能需加项（电流线性项 K·I，天津模型）或放宽 |
| 瞬态 100W 误差 | 惯性功率物理无解 | 裁判 60J 能量缓冲 / 负功率电机剔除预算（西浦）兜底 |
