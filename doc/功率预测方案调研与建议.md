## 0. 一句话结论

**不要换算法。** 当前管线「损耗模型预测 + RLS 在线辨识 + 隶属度分配 + 二次方程限矩」正是所有成熟战队里最主流、最先进的家族（港科大 2024 / COD 2026 就是这个家族的公开实现）。K1 漂移不是算法族选错了，是**双参数共线辨识 + 缺保护门控**。fix-K2 计划方向正确，只需再补三个防漂移闸门，大概率收敛。换算法（退化成离线拟合冻结 / 能量缓冲限幅）是**降级**——有真实功率计在线闭环能力，这是顶级队的配置。

## 1. 六仓库逐家详解

### 1.1 `Power`（STM32F103C8 + INA226 功率采集板固件）

**结论：不涉及功率预测。** 纯采集/转发板。500Hz 定时读 INA226 的 U/I/P，CAN 0x605（4×int16）+ VOFA+ 串口上送。全仓无公式、无 K1/K2/K3、无转矩/转速物理量。

- 功率"换算"仅一条：`P = raw_p × 25.0 × g_CurrentLSB`（INA226.c:135，`g_CurrentLSB=32.7/32767`）
- 唯一可借鉴点：**按 MCU UID 查表自适应分流电阻**（INA226.c:10-14）——硬件配置识别思路

> ⚠️ 这是用户功率计的来源：`framework/modules/powermeter/powermeter.cpp` 解析的正是同款 INA226 板（CAN 收 shunt/bus/current/power，power 按 **int16 有符号**×0.01W 解析）。→ 功率计**能看到再生负功率**（裁判系统看不到），这是硬件优势。

### 1.2 西交利物浦 GMaster 2023（Wenhao Lin, MIT）

**离线标定型**，系数写死，无在线辨识。

**模型**（chassis_power_control.c:25-28, 64-66）：

```
P_i = toque_coefficient·Icmd·ω + a·Icmd² + k2·ω² + constant
    = 1.99688994e-6·Icmd·ω + 1.23e-7·Icmd² + 1.453e-7·ω² + 4.081
```

- `Icmd` = 速度环 PID 输出（give current，±16384），`ω` = 转子 RPM
- `toque_coefficient` 完整推导：(20/16384)·(0.3)·(187/3591)/9.55 —— **转矩常数除以减速比换算到转子**
- 标定：INA226 采样 `P_other = P_in − P_machine`，MATLAB 拟合 `k1ω²+k2·Icmd²+c`（power_model.m:30-34），12 组工况数据

**分配**：前向算各电机功率 → **负功率（回馈）电机 continue 跳过、不计入预算、不参与缩放** → `power_scale = max_power / ΣP` 等比缩放（:68-78）。

**限幅**：解二次方程 `a·Icmd² + b·Icmd + c = 0`（b=toque·ω, c=k2ω²−scaled+const），**按 PID 原方向取 ±√ 根**，钳位 ±16000（:84-110）。

**超级电容**：30J 缓冲 PID → `CAN_CMD_CAP(input_power)`，电容>5% 时预算 +5W/+200W（:30-60）。

**对本项目价值**：无在线学习的**对照基线**。若固定系数在同样工况下预测稳、而 RLS 的 K1 漂，就证明漂移出在辨识环节而非模型结构。三个工程细节值得抄：**负功率电机从预算剔除、二次方程按原方向选根、电容缓冲联动抬高预算**。

### 1.3 天津工业大学 304（PowerManager）

**离线 6 项多项式最小二乘**，系数写死，无在线辨识。26 赛季 RMUL 实测无明显超功率。

**模型**（power_manager.cpp:40-45，old_version/powerctrl.h:16-28）：

```
W = (K0 + K1·I + K2·ω + K3·I·ω + K4·I² + K5·ω²) × power_sign
M3508: K0=0.65213, K1=-0.15659, K2=0.00041660, K3=0.00235415, K4=0.20022, K5=1.08e-7
```

- `I=|current/1000|`，`ω=|rpm|`；`current×speed<0` 且开 `E_enable_negative` 时 `power_sign=-1`（发电取负）
- 拟合：`Fitting.py` `np.linalg.lstsq`（含 3σ 异常剔除、R²/MSE 评估），一次离线定死

**分配**（power_manager.cpp:162-203）：按速度误差比例 + **每电机预留 8W 基准**——防高速突变时某电机分到极小功率导致衰减方程无解（作者实测踩坑核心技巧）。总功率先乘 (1-0.02) 安全余量。

**限幅**：预测功率超限时解衰减系数 k 的二次方程（a=K4·I², b=(K1+K3·ω)·I, c=K0+K2·ω+K5·ω²−P_limit），`实际电流 = 原电流 × k`，k∈(0,1)（:59-158）。

**对本项目价值——最重要的一条**：**当前模型缺线性项。** 天津模型有 `K1·I`、`K2·ω` 两个线性项和 `K3·I·ω` 交叉项，能**显式吸收固定/线性损耗偏置**；当前 `P=K1·τ²+K2·ω²+τ·ω+K3` 没有线性项，**所有未建模偏置全被单一 K1 吸收**——这正是 K1 持续单调漂移（0.4→1.16）而 K2 稳定的**最可疑结构根源**。另借鉴：小陀螺旋转降额/θ前馈补偿（:278-306）。

### 1.4 香港科技大学 ENTERPRIZE 2024（PowerModule，C++/FreeRTOS）⭐ 与本项目最同源、最成熟

**RLS 在线辨识族的天花板**，且**刻意做了防共线设计**。

**模型**（PowerController.cpp:141, README.md:36-52）：

```
P_i = τ_i·ω_i + k1·|ω_i| + k2·τ_i² + k3/4
整车: P = Στ·ω + k1·Σ|ω| + k2·Στ² + k3
```

- `τ = pidOutput·k0`（k0 = 电机KA×减速比×限流/输出限幅），`ω = rpm·π/30`
- 默认 k1=0.22、k2=1.2、k3=2.78（**k3 离线标定：失能电机取静态功率平均**）
- **刻意没有 ω² 项**！README.md:140 原话：*"别的关于转速平方，力矩一次的损耗项可以忽略为0"* —— 用 `k1·|ω|` 线性项代替 ω²，**从模型结构上消除与 τ² 的共线性**

**在线辨识**：RLS 只辨 2 参（[Σ|ω|, Στ²]），`rls(1e-5f, 0.99999f)`（与当前参数一模一样），目标 `y = P_meas − Στ·ω − k3`。

**防漂移保护（对应 K1 漂移，三条对策全在这）**：

| 门控 | 作用 |
|------|------|
| `|measuredPower| > 5.0W` 死区 | 小功率段 SNR 差，跳过更新 |
| **电容断连且 estimatedPower<0 时跳过** | 裁判测不到负功率 → 负功率期间残差被系统性抬升 → 不更新 |
| **每次更新后 k1/k2 = fmax(k, 1e-5) 下限钳位** | 防系数发散为负 |

**分配**：误差置信度 `K_coe`（Σerror>20→1, <15→0 线性插值）→ `powerWeight = K_coe·(err_i/Σerr) + (1-K_coe)·(cmdPower_i/ΣcmdPower)`；**负功率轮直通 PID、负功率回填预算**。

**限矩**：二次方程 `k2τ²+ωτ+(k1|ω|+k3/4−P_i)=0`，**Δ<0 取最小功耗点 τ=−ω/(2k2)**（无数值迭代）。

**能量环**：`P_max = refereeMax − PD(√E_set, √E_buff)`，sqrt(E) 非线性过渡，保底 0.8×referee。1000Hz powerDaemon。

### 1.5 COD 2026 舵轮哨兵（辽宁科技大学，STM32H723）

**与当前方案几乎逐字同源**（XJTLU 模型 + HKUST 隶属度分配），但注意它对漂移的应对：

- 模型 `P_in = K1·τ² + K2·ω² + τ·ω`（K3 组求和时统一加），τ=电流×4.577e-5，ω=rpm/9.55（Control_Task.c:867/873）
- RLS 配置 `RLS_Init(4,1,0.99999,1e-5)`（:178）——**λ、P0 完全一致**
- **特征完全不做归一化**（Στ²~1e-3 vs Σω²~1e6，差 9 个数量级）→ 条件数极差，正是 RLS 系数缓慢单调漂移的经典成因
- **它把 RLS 注释掉了**（:898 `// RLS_Update(...)`），用固定 K1=1.453e-7、K2=1.23e-7。文档把在线自整定降级为可选项，并提醒"需额定工况跑 30~60s 使参数稳定"（README.md:523-535）
- 舵向组固定 80% 预算、行进组拿剩余（:880/887）；超电能量环 PID_Buffer 目标 60J，超电≥15% 加 100W（:586-598）

**对本项目价值**：**最直接的旁证**——连几乎同源的队，最终都选择"比赛代码冻结系数、回避在线辨识不稳定性"。当前已用 Σω²/1000 归一化（比它强），但 τ²/ω²/τ·ω 三组量纲仍差 3~9 个数量级。

### 1.6 英雄底盘功率控制（HeroPowerControl, 2018）

**无模型对照组**。不做任何预测，纯能量缓冲反馈限幅：

```
总输出上限 = buffer² × 6.0（chassis.c:86-89），buffer<50J 触发，30ms 丢包强制 buffer=5J
分配 = 各电机 |PID输出| 占总和比例 等比缩放（保方向）
```

- 无 RLS/无转矩感知/无法预测瞬时功率。**对 K1 漂移无解释力**，仅作最简"裁判能量反馈→限幅"对照组，理解 RLS 期望输出从哪来。

## 3. 对当前方案的关键洞察（K1 为什么漂）

交叉验证后，K1 单调漂移 0.4→1.16 有**三层原因**，规划文档只覆盖了第一层：

1. **共线性（已识别）**：Στ² 与 Σω² 在加减速时高度相关 → 2 参 LS 解不唯一 → K2 有更好的激励覆盖先稳，残差全被 K1 吸收。✅ fix-K2 计划根治。

2. **λ=0.99999 慢遗忘 × 任何系统性偏置 = 单调随机游走**（COD/港科大共同印证）：λ 接近 1，每次更新极其微小。只要存在**固定 K3 不准 / Kτ·ω≠1 / 未建模线性摩擦 / 功率计零偏**中任意一项，持续的小残差就会**单调地**灌进约束最弱的方向（K1）。K1 单调上涨 3 倍、K2 纹丝不动，正是这个签名。

3. **模型结构缺线性项**（天津的洞察）：摩擦/铁损在底盘转速段更接近**线性于 ω**（港科大用 k1·|ω|，西浦/天津都有线性项），ω² 是个更差的拟合形态且与 τ² 共线。所有未建模偏置只能往 K1 里灌。

> 好消息：港科大对 2、3 有现成对策（死区/负功率跳过/下限钳位/去 ω²），且功率计能看到带符号功率（比港科大"裁判测不到负功率"的工况更好），负功率门控可以放宽。

## 4. 建议：怎么做 / 要不要换算法

### 结论：不换算法族，fix-K2 继续，追加 3 个闸门

**阶段 A —— 立即执行（fix-K2 计划 §3/§4 照做）** ✅ 正确
固定 K2=0.0066、单参数 RLS 只辨 K1，从根上消除共线。这本身就是所有成熟队的共识方向（港科大最小 2 参、COD 直接冻结）。**K1 初值按计划 §5 改 0.4f**（接近稳定段实测，收敛更快）。

**阶段 B —— 在 fix-K2 基础上追加 3 个防漂移闸门（港科大的现成方案，几行代码）** ⭐ 推荐必加
1. **实测功率死区**：`|measuredPower| < 5W` 时跳过 RLS 更新（小功率段 SNR 差，残差是噪声）。
2. **K1 下限钳位**：每次更新后 `k1 = fmax(k1, 1e-5)`（防系数被推到负/发散）。K2 已固定不用钳。
3. **负功率时段弱化更新**（可选，因功率计能看到负功率，可放宽为"`τ·ω < 0` 且 |P_meas| 极小"才跳过）——防止再生制动段残差被机械功率失配主导时污染 K1。

**阶段 C —— 烧录后按计划 §6 验证，并做"模型 vs 辨识"分离诊断**
- 若 fix-K2 后 **K1 1000 行内收敛且波动 <10%、误差 ~3W** → 收工，固化 `rlsEnable=false`（计划 §6.5）。
- 若 **K1 仍漂或误差 >5W** → 说明是**模型结构问题**而非辨识问题。此时再跑一次 `rlsEnable=false` 固定系数基线对照：
  - 固定基线预测也差 → 模型结构不足 → **迁移港科大模型**：`P = τ·ω + k1·|ω| + k2·τ² + k3`（去 ω²、加线性项），这是治本。
  - 固定基线预测好 → 辨识环节问题 → 调 λ（更大）或检查 K3/Kτ·ω 固定项精度。

**阶段 D —— 只有一种情况才"换算法"**：在线辨识在比赛环境始终不稳，且评估**自适应能力收益 < 稳定性风险**。这时退化成**天津/西浦式离线拟合冻结**（用现有 temp.txt 数据离线 lstsq 一次拟合 K0~K5 冻结）。但有真实功率计、架构支持在线，**不建议主动退化**。
