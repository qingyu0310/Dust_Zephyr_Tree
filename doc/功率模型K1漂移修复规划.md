### 1.3 调研新增根因（三层，v2 新增）

temp/ 六仓库交叉验证后，K1 漂移有**三层原因**，v1 只覆盖第一层：

1. **共线性**（v1 已识别）：Στ² 与 Σω² 在加减速时高度相关 → 2 参 LS 解不唯一 → K2 激励覆盖先稳，残差全被 K1 吸收。✅ fix-K2 根治。
2. **λ=0.99999 慢遗忘 × 系统性偏置 = 单调随机游走**（港科大/COD 印证）：λ 接近 1，每次更新微小；只要存在固定 K3 不准 / Kτ·ω≠1 / 未建模摩擦 / 功率计零偏任一项，持续小残差**单调**灌进 K1。→ **对策：死区 + 系数下限钳位 + 负功率门控**。
3. **模型结构缺线性项**（天津洞察）：摩擦/铁损接近线性于 ω（港科大用 k1·|ω|），无线性项则所有偏置被单一 K1 吸收。→ 本次**不改模型**（归入 §8 兜底），先验证辨识层面。

> 功率计零偏说明：空载 3W 是真实静态功耗 K3（已建模），非零偏；零偏量级 0.1~0.3W 可忽略。

## 2. 决策（v2，用户已确认方向 + 调研补充）

1. **K2 固定 = 0.0066**（稳定段取值）
2. **K1 单参数在线辨识**（固定 K2 后回归量只剩 Στ²，无共线干扰）
3. **追加防漂移闸门**（港科大方案）：
   - 死区：`|P_meas| < 5W` 跳过更新
   - 系数下限钳位：`k1 = fmax(k1, 1e-5)`
   - 负功率门控：`skipNegPower`（**true**，预测功率<0 跳过——停车/急刹时模型预测负、功率计读正，残差会顶飞 K1）
4. 减速 τ·ω 负值问题本次不处理（钳制已兜底显示；负功率门控为其留了开关）

## 3. power_ctrl.hpp 改动（核心，逐处 old→new）

### 3.1 Config 加 fixK2 + 三个闸门参数

```cpp
// old

        bool    rlsEnable  = false;             // false = 使用固定 K1/K2

// new
        float   powerMax     = 0.0f;            // 总功率钳制上限（0=不钳制；底盘传总预算 60）
        bool    fixK2        = false;           // true=固定 K2 只辨 K1（单参数，防共线漂移）
        float   deadzonePower = 0.0f;           // RLS 更新死区：|P_meas|<此值跳过（0=不启用；港科大 5W）
        float   kFloor       = 1e-5f;           // 辨识系数下限钳位（防发散为负）
        bool    skipNegPower = false;           // true=预测功率为负（再生制动/停车）时跳过 RLS 更新
        bool    rlsEnable  = false;             // false = 使用固定 K1/K2
        bool    tauOmegaEnable = true;          // 是否包含 τ·ω 项
```

### 3.4 Predict() RLS 段：三闸门 + fixK2 分叉 + 下限钳位

```cpp
// old
        if (rlsInited_ && powerValid_ && (sumOmega2_ >= cfg_.excMinOmega2 || sumTorque2_ >= cfg_.excMinTau2))
        {
            float target = measuredPower_ - cfg_.k3;
            if (cfg_.tauOmegaEnable) {
                target -= kTauOmega_ * sumTauOmega_;  // 减掉已知机械功率，残差 = 铜损 + 铁损
            }

            // 回归量归一化：Σω² 除以 S，消除 4500 倍尺度差（根因详解 §8.1）
            // 物理关系：K2_phys = K2'(归一化空间) / S
            float x[2] = { sumTorque2_, sumOmega2_ / cfg_.omega2Scale };
            rls_.Update(x, target);
            k1_ = rls_.GetWeights()[0];
            k2_ = rls_.GetWeights()[1] / cfg_.omega2Scale;   // 归一化空间 → 物理值
        }

// new
        // RLS 更新门控：激励 + 死区 + 负功率（港科大防漂移三闸门）
        // ① 激励门控：Σω²/Στ² 任一达标才更新（原有）
        // ② 死区：|P_meas| < deadzonePower 跳过（小功率段 SNR 差，残差是噪声）
        // ③ 负功率门控：skipNegPower 且 预测功率<0（再生制动/停车）跳过
        //    —— 制动时模型预测负功率、功率计读正（再生被吸收），残差被机械功率失配主导，
        //       会把 K1 顶飞（港科大用 estimatedPower<0 门控，不是 P_meas<0）
        if (rlsInited_ && powerValid_ &&
            (sumOmega2_ >= cfg_.excMinOmega2 || sumTorque2_ >= cfg_.excMinTau2) &&
            fabsf(measuredPower_) >= cfg_.deadzonePower &&
            !(cfg_.skipNegPower && GetTotalPower() < 0.0f))
        {
            float target = measuredPower_ - cfg_.k3;
            if (cfg_.tauOmegaEnable) {
                target -= kTauOmega_ * sumTauOmega_;  // 减掉已知机械功率，残差 = 铜损 + 铁损
            }

            if (cfg_.fixK2) {
                // 单参数模式：固定 K2，只辨 K1
                // target 减掉固定 K2 铁损，回归量只剩 Στ²，K1 无共线干扰
                target -= cfg_.k2Init * sumOmega2_;
                float x1[1] = { sumTorque2_ };
                rls1_.Update(x1, target);
                k1_ = fmaxf(rls1_.GetWeights()[0], cfg_.kFloor);   // 下限钳位防发散为负
                k2_ = cfg_.k2Init;                                  // 固定 K2
            } else {
                // 双参数模式（原有逻辑，只加下限钳位）
                float x2[2] = { sumTorque2_, sumOmega2_ / cfg_.omega2Scale };
                rls_.Update(x2, target);
                k1_ = fmaxf(rls_.GetWeights()[0], cfg_.kFloor);
                k2_ = fmaxf(rls_.GetWeights()[1] / cfg_.omega2Scale, cfg_.kFloor);
            }
        }
```

> 物理验证：单参数模式 `target = P_meas − K3 − τ·ω − 0.0066·Σω²`，`K1 = target/Στ²` 的在线最小二乘，纯单参数，必然收敛；死区与下限钳位只挡噪声与发散，不改变收敛点。

## 8. 兜底（阶段 C/D：本次不做，验证失败才走）

**分离诊断**：若 fix-K2 后 K1 仍漂或误差 >5W，跑一次 `rlsEnable=false` 固定系数基线（K1=0.4, K2=0.0066）：
- 固定基线预测好 → **辨识环节问题** → 调 λ（更大）或检查 K3/Kτ·ω 固定项精度
- 固定基线预测差 → **模型结构问题** → 迁移港科大模型 `P = τ·ω + k1·|ω| + k2·τ² + k3`（去 ω² 加 |ω| 线性项，治本），另出规划

**最后兜底**：在线辨识始终不稳时，退化为天津/西浦式离线拟合冻结（用 temp.txt 离线 lstsq 拟合 K0~K5 冻结）。有真实功率计、架构支持在线，不建议主动退化。

## 10. v3 模型结构改动：港科大模型（去 ω² 加 |ω|）✅ 已实现

> 2026-08-05。**§8 兜底生效**：双参数辨识确认共线复发（下地加负载跑，K1/K2 全程反相关：K1 降时 K2 升，解不唯一），迁移港科大模型根治。

### 10.1 模型变更

```
旧：P_i = K1·τ² + K2·ω² + τ·ω + K3/4     RLS x=[Στ², Σω²]，Σω² 归一化 ÷1000
新：P_i = k1·τ² + k2·|ω| + τ·ω + K3/4    RLS x=[Στ², Σ|ω|]，无归一化
```

- **k1 = τ² 铜损系数**（GetK1，语义不变，值 2.20 作初值）
- **k2 = |ω| 转速线性损耗系数**（GetK2，替代原 ω² 铁损，值 0.10 作初值，由 0.0066·ω² 在 ω≈15 等价换算）
- 转速损耗从平方 ω² 改线性 |ω|：消除与 τ² 的共线（开车时 τ²、ω² 同涨），双参数可唯一辨识
- 去 omega2Scale 归一化（Σ|ω|~40 vs Στ²~4，量级差 ~10x 良性，无需 S）
